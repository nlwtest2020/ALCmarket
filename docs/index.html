Core Features

Facebook Tracking

Monitor public competitor pages for followers, posts, engagement metrics, and posting frequency.

  • Follower counts
  • Post engagement (likes, comments, shares)
  • Posting frequency analysis
  • Video content detection
Instagram Tracking

Track competitor Instagram profiles for followers, engagement, and content strategy analysis.

  • Follower & following counts
  • Engagement rate tracking
  • Content type analysis (image, video, carousel)
  • Growth trend detection
Website Monitoring

Detect significant changes to competitor websites including pricing and course updates.

  • Pricing page changes
  • Course curriculum updates
  • Change diff preview
  • Historical change tracking

Key Metrics Tracked

Growth Metrics
  • Follower Counts - Real-time tracking on Facebook & Instagram
  • Follower Growth - Track growth trends over 30/60/90 days
  • Following Ratio - Engagement quality indicator
  • Total Posts - Content library size and activity level
Engagement Metrics
  • Engagement Rate - Avg likes, comments, shares per post
  • Posting Frequency - Posts per week analysis
  • Content Types - Video, image, carousel breakdown
  • Video Percentage - Video content strategy indicator
Website Metrics
  • Pricing Changes - Course pricing updates detected
  • Course Updates - New courses and curriculum changes
  • Change Percentage - How much of the page changed
  • Diff Preview - Exact lines that changed
Trend Analysis
  • Historical Data - Build trends over time
  • Change Detection - Alerts on significant updates
  • Competitor Benchmarking - Compare performance across markets
  • Growth Projections - Estimate future growth patterns
